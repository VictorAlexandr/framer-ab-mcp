The insight

The data was never locked.
It was in GA4 all along.

When Framer assigns a visitor to a variant, it stamps the URL. If your site sends data to Google Analytics 4 — most production Framer sites do — every variant is already tracked separately, behind an official, stable Google API.

🧪

Framer runs the test

A visitor gets assigned to a variant and lands on:

/pricing?framer_variant=dXmgUoIf7
📊

GA4 records it — split by variant

The landingPagePlusQueryString dimension keeps the stamp. Visitors, key events, everything — per variant, per day.

⚡

framer-ab-mcp does the math

Auto-detects tests from traffic, aggregates variants across query noise (utm, fbclid…), runs a two-proportion z-test at 95% confidence.

Quickstart

Running in three steps

Connect GA4 to your Framer site

Site Settings → Integrations → Google Analytics. Mark your lead / purchase event as a key event in GA4 so conversions mean what you think they mean.

Create GA4 API credentials (2 min)

Google Cloud → enable the Analytics Data API → create a service account → add its email as Viewer on the GA4 property → download the JSON key.

Add the server to your MCP client

Claude Code, Claude Desktop, Cursor, Windsurf — anything that speaks MCP:

{
  "mcpServers": {
    "framer-ab": {
      "command": "npx",
      "args": ["-y", "framer-ab-mcp"],
      "env": {
        "GA4_PROPERTY_ID": "123456789",
        "GOOGLE_APPLICATION_CREDENTIALS": "/path/to/key.json"
      }
    }
  }
}

Honest FAQ

What it is — and isn't

Is this scraping Framer's dashboard?

No. It only calls the official Google Analytics Data API, on data your own site sends to your own GA4 property. Nothing touches Framer's servers — so nothing breaks when Framer ships a redesign.

Does it cover Framer's native funnels and CTA click tracking?

No. Those metrics exist only inside Framer's panel, which has no API — and this project deliberately stays on the official-API side of that line. If Framer ever ships an analytics API, this server is the natural place to plug it in.

What about visitors from before the test started?

They land without a framer_variant stamp and are reported separately as (baseline) — never contaminating variant numbers. Baseline is the default control; override with controlVariantId.

Which AI clients work?

Anything that speaks MCP over stdio: Claude Code, Claude Desktop, Cursor, Windsurf, and the growing list of MCP-compatible agents.
